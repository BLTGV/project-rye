Project: Project Rye
Type: Agent-native temporal knowledge graph schema for PostgreSQL
URL: https://projectrye.dev
Source of truth: Markdown files in /docs and /design
Repository: https://github.com/BLTGV/project-rye

Positioning:
- Rye is an open source SQL schema, not a database, application, or framework.
- Rye gives agents a temporal graph for entities, relationships, activities, assertions, and artifacts.
- Domain tables remain the system of record; Rye overlays them through link_record() and track_table().
- The recommended repo-local entrypoint is ./scripts/rye for init, doctor, catalog, context, sources, and onboarding.
- Portable metadata includes plugin catalogs, skill catalogs, capability catalogs, and agent context bundles.
- Scope-first onboarding and plugin policy bundles guide what agents may collect, classify, retain, and promote.
